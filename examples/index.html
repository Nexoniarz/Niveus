Examples

Four products, one system.

Each of these is a complete interface built from Niveus and nothing else. They look like different products because they are — but none of them overrides a component, forks a token, or writes a color. What differs is one declaration of --nv-brand, and the layout each one needs for its own content.

Open any app.css beside them: it contains grids, widths and breakpoints, and not a single hex value. That split — the system owns the language, the application owns the layout — is the thing these examples are really demonstrating.

How to read these

Every example links exactly two files from the system — dist/niveus.css and the optional niveus/niveus.js — then its own app.css for layout. Nothing else is shared between them.

Where one of them needed something the system did not have, the answer was to add it to the system, not to the page: the badge and table components exist because these examples asked for them.
