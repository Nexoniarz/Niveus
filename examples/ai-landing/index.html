Questions

Before you ask.

Do you train on our code?
No. Repository contents are used to answer your team's questions and nothing else. Enterprise plans can run entirely inside your own network, where the question never leaves it either.
What happens when it is wrong?
Every answer cites the files it drew on, so a wrong answer is checkable rather than merely confident. Anything that writes is a proposal until a person approves it.
How large a codebase can it handle?
The largest repository we index in production is around eleven million lines. Indexing is incremental, so size affects the first run far more than the ones after it.
